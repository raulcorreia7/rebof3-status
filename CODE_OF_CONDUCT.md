# Code of conduct

This project follows the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behavior privately: open the repository's Security tab and choose
[Report a vulnerability](https://github.com/raulcorreia7/bof3-status/security/advisories/new).
Only the maintainer sees the report.
